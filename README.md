# 🌍 Jornada Viagens

Um site responsivo de agência de viagens desenvolvido com **HTML**, **CSS** e foco em **design responsivo**.

**Link do projeto:** [jornada-viagens-indol.vercel.app](https://jornada-viagens-indol.vercel.app)

## 📋 Sobre o Projeto

Projeto desenvolvido durante o **curso de Responsividade** da formação Front-End da Alura, com o objetivo de aplicar conceitos modernos de design responsivo e garantir uma excelente experiência em diferentes dispositivos.

O site apresenta um catálogo de pacotes de viagem com interface intuitiva e navegação fluida.

## 🎯 Funcionalidades

- ✅ **Design Responsivo** - Otimizado para desktop, tablet e mobile
- ✅ **Páginas do Site:**
  - Home (página inicial)
  - Pacotes de Viagem
  - Blog de Viagens
- ✅ **Navegação Intuitiva** - Menu principal e links internos
- ✅ **Assets Customizados** - Fontes e ícones próprios
- ✅ **Deploy em Produção** - Hospedado no Vercel

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilos e responsividade
- **Fonts Customizadas** - Tipografia personalizada
- **Vercel** - Deploy e hospedagem

## 🚀 Como Usar

### 1. **Clone o repositório**
```bash
git clone https://github.com/VHTORRES/jornada-viagens.git
cd jornada-viagens
```

### 2. **Abra o projeto**
Simplesmente abra o arquivo `index.html` em seu navegador:
```bash
# No Linux/Mac
open index.html

# No Windows
start index.html
```

Ou use uma extensão como **Live Server** (VS Code) para desenvolvimento local.

### 3. **Acesse o site em produção**
Visite: [jornada-viagens-indol.vercel.app](https://jornada-viagens-indol.vercel.app)

## 📱 Responsividade

O projeto foi desenvolvido seguindo o **Mobile-First Approach**, garantindo excelente experiência em:
- 📱 Smartphones (320px+)
- 📱 Tablets (768px+)
- 🖥️ Desktops (1024px+)
